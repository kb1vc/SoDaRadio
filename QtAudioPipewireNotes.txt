OK google AI to the rescue (hawk-ptuuuii).
do This:
#!/bin/bash

#set up the mixed sound sink
pactl load-module module-null-sink sink_name=RadioOutput \
      sink_properties=device.description="RadioOutput"
pactl load-module module-null-sink sink_name=ModemOutput \
      sink_properties=device.description="ModemOutput"

# set up the inputs
pactl load-module module-null-sink media.class=Audio/Source/Virtual sink_name=ModemInput channel_map=front-left,front-right
pactl load-module module-null-sink media.class=Audio/Source/Virtual sink_name=RadioInput channel_map=front-left,front-right

# connect them
pw-link RadioOutput:monitor_FL ModemInput:input_FL
pw-link RadioOutput:monitor_FR ModemInput:input_FR

pw-link ModemOutput:monitor_FL RadioInput:input_FL
pw-link ModemOutput:monitor_FR RadioInput:input_FR

# Alternatively we can
#pactl load-module module-loopback source=RadioOutput:monitor_FL sink=ModemInput:input_FL
#pactl load-module module-loopback source=RadioOutput:monitor_FR sink=ModemInput:input_FR

#pactl load-module module-loopback source=ModemOutput:monitor_FL sink=RadioInput:input_FL
#pactl load-module module-loopback source=ModemOutput:monitor_FR sink=RadioInput:input_FR

================

Then the Radio/Modume Output/Input devices are detected.

But the system mic input may not be. In this case, go to system settings and select the microphone input. It will then be recognized as the default.  Dunno why.

To set up a microphone as default input:

use pactl list short sources to find the likely device name
then do this:

> pactl set-default-source alsa_input.pci-0000_00_1f.3.analog-stereo
